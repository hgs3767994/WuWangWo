# 莫忘

在忙碌的日常中，我們總希望能好好記住對方的喜好、彼此經歷的事件與互動中的溫暖細節。**「莫忘」** 是一款專為人際關係與故事紀錄打造的人物誌工具。無論是用於專業的客戶資料管理，或是日常珍藏親朋好友的性格偏好與重要回憶，「莫忘」都能為你梳理出清晰且帶有溫度的人際脈絡。

作為一款現代化的 **PWA（Progressive Web App）**，它不需要經由應用商店安裝，也能提供跨平台、可安裝至主畫面、即開即用的使用體驗。同時將資料自主權保留在使用者手中，兼具本機保存與雲端備份的彈性。

#### ✨ 核心特色與技術亮點

- **深度人物檔案**：超越傳統通訊錄，完整記錄個人的喜好、偏好細節、性格特質與專屬記事。
- **事件與回憶時間軸**：記錄每一次互動、拜訪或重要事件，隨時溫習彼此的交集與故事。
- **PWA 輕量架構**：無需經由應用商店下載，支援跨裝置安裝至主畫面，並提供離線使用體驗。
- **本機／雲端雙模式**：預設資料儲存在使用者本機裝置；也可自由選擇連結個人的 Google Drive 進行備份與同步。
- **本機加密後同步**：連結 Google Drive 後，人物資料會在上傳前於使用者裝置中加密，再寫入 Google Drive 的 App 專用資料空間，降低雲端資料外洩風險。
